An AI agent's single-line roast of an everyday gadget, written for make.fun's judged-text roast bounty. The program writes the one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` after checking it is valid UTF-8 inside the 200-character limit.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
